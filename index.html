Why RAWdemption exists

RAWdemption began when I decided not to renew Lightroom. I wanted a simpler way to work through my photos: pick the keepers, adjust them, export.

The free editors I tried were capable, but I never settled into using them. So I built this. It's now the editor I use for my own photography.

I've made it available for other photographers with a similar routine. Photos stay in their folders, edits are saved alongside them, and editing and exporting are free.

Free forever, for anyone.

RAWdemption is made by one person. If it earns a place on your Mac, you can support it on Patreon.

Questions

Which cameras does it open?

RAWdemption develops RAW files with the RAW engine built into macOS, so it opens what Apple Photos opens: most cameras from Canon, Fujifilm, Leica, Nikon, Olympus/OM System, Panasonic, Pentax/Ricoh, Sony and more, plus DNG. Apple publishes the full list on its support site (“Digital camera RAW formats supported by macOS”), and new cameras arrive with macOS updates. JPEG, HEIC, PNG and TIFF open too.

Does it change my photos?

Never. Originals are only read. Each edit is a small recipe saved in a hidden .lightbox folder beside the photos, along with your favourites, so edits travel with the folder to another drive or Mac. Exports are always new files.

Which Macs does it run on?

Macs with Apple silicon (M1 or later) on macOS 13 Ventura or later. 16 GB of memory is recommended for smooth editing of 24-megapixel RAW files; Intel Macs aren't supported.

Why install with a Terminal command?

RAWdemption isn't sold through the App Store and isn't notarised by Apple yet, which takes a paid developer membership. Without it, macOS calls the app “damaged” when a browser downloads it, and offers no way to open it. Nothing is wrong with the file: the one-line command downloads it the way Terminal does, so it arrives without that label, checks that it's intact and really RAWdemption, puts it in Applications and opens it. Updates then install from inside the app, signed, with nothing more to do.

Can it replace Lightroom?

For many hobbyists, yes: it covers what most people use day to day, with faster, calmer editing. If your work depends on catalogues across many drives, tethered shooting, print layouts or plugins, RAWdemption isn't meant for that, and that's by design.

Is it finished?

Not yet. RAWdemption began as my own editor and is now in public beta. More advanced features can follow over time. If something breaks or looks off, please be kind and report it to me with Help › Report a Problem: every report helps make RAWdemption better for as many photographers as possible.

Install RAWdemption

Version 0.9.12 beta · 2.6 MB download, 7.0 MB installed · Apple silicon · macOS 13 or later · 16 GB memory recommended · RAW, JPEG and HEIC
  1. Open Terminal (Applications › Utilities, or press ⌘ Space and type Terminal).
  2. Paste this line and press Return:
    curl -fsSL https://hobocow.github.io/rawdemption/install.sh | bash
  3. RAWdemption downloads, moves itself to Applications and opens. That's it: from then on, updates arrive inside the app.

Why a command? RAWdemption isn't notarised by Apple yet (that takes a paid developer membership), and macOS labels such apps “damaged” when a browser downloads them. They aren't; the command simply installs without that label. Prefer the zip? Download it, move RAWdemption to Applications, then run xattr -dr com.apple.quarantine /Applications/RAWdemption.app once in Terminal.
